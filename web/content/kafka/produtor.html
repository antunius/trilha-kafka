Produtor (producer)

O que é. Biblioteca no seu processo (aqui: KafkaTemplate / cliente Java). Serializa key e value → escolhe partição → junta records num batch → ProduceRequest para o líder → espera ACK conforme acks → retry se falhou. Sem enable.idempotence, o retry do mesmo producer cria duas linhas no log. O Kafka não cobra cartão: só grava bytes.

Analogia: quem escreve no final da coluna. Pode ser a API, um conector, um script.

Na prática. Classe do lab e o endpoint:

kafka.send(topic, pedidoId, evento)
    .whenComplete((result, ex) -> {
      var meta = result.getRecordMetadata();
      // meta.partition(), meta.offset()
    });
curl -X POST "http://localhost:8080/pedidos?pedidoId=99&totalCentavos=8000"

No lab. PedidoProducer.java + PedidoController POST /pedidos. Serializer: KafkaJsonSchemaSerializer (Registry na porta 8081).

“Mandei” no log da aplicação não é “o ISR confirmou”. Trate o whenComplete / o CompletableFuture do send. Sem key, a ordem do pedido 99 não existe — lab 1.
